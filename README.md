# 余白習慣

三日坊主になりやすい人向けの、スマホ前提の習慣化支援PWAです。認知負荷を抑え、小さく始めて、止まっても戻れることを中心に設計しています。実行、設計、調整、保管の4導線で、最小版、既存ルーティンへのアンカー、If-Thenプラン、1タップ記録、復帰導線、週次レビュー、ローカル保存を実装しています。

## 使い方

```bash
python3 -m http.server 4174 --bind 127.0.0.1
```

ブラウザで `http://127.0.0.1:4174/` を開きます。

## テスト

```bash
node --test
```

## 設計メモ

- 記録はストリークではなくコンシステンシー指数を中心にしています。
- 未完了を赤い失敗として扱わず、最小版で戻る導線を出します。
- 習慣入力は縦長フォームではなく、1画面1問のステップ式にしています。
- 未実行理由、復帰回数、習慣の難易度、ライフサイクル状態を見られます。
- 週次レビューはMarkdown、記録はCSVでも書き出せます。
- データはローカルストレージに保存します。サーバー送信、位置情報取得、健康データ取得は行いません。
- 通知はブラウザ権限の確認のみです。バックグラウンドのプッシュ通知配信はサーバー実装が必要です。
- 研究根拠と実装への翻訳は `docs/research-notes.md` に整理しています。
