# デザイン再構築メモ

添付の `WebApp Design_v1` をもとに、既存の見た目を前提にせず、習慣化ツールを「低認知負荷の実行アプリ」として再構成した。

## 反映した原則

1. セマンティックトークン
   - `bg`, `fg`, `border`, `accent`, `shadow`, `space`, `radius` を役割ベースで再定義した。
   - ライト/ダークテーマを `data-theme` で切り替える構成にした。

2. Calm Interface
   - 装飾よりも、今日の一手、最小実行、復帰対象、調整メモを前面に出した。
   - ストリーク中心ではなく、復帰回数と最小版を評価軸にした。

3. 情報設計
   - 画面を `実行 / 設計 / 調整 / 保管` の4導線に整理した。
   - 今日画面は「残り数 -> 1つの最小版 -> 記録」の順にした。
   - 習慣入力は縦長フォームをやめ、`名前 / 通常版 / 最小版 / きっかけ / 戻り方` のステップ式にした。

4. 日本語UI
   - 日本語と英数字が混在しても崩れにくいフォントスタック、行間、禁則寄りの設定にした。
   - ボタンやカードの長い文言が折り返しても操作領域を保つようにした。

5. アクセシビリティ
   - 主要操作は48px以上を維持した。
   - 色だけでなく、文言と状態ラベルで完了、最小版、未実行を区別した。
   - Reduced Motion の設定を尊重する。

## 主な変更対象

- `index.html`
- `styles.css`
- `src/app.js`
- `tests/smoke-playwright.mjs`
